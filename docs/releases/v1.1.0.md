# LocalRack v1.1.0

LocalRack now comes with a Windows installer, and it no longer uses CPU while your services are quiet.

## Highlights

- **Windows installer.** `LocalRack-v1.1.0-win-x64-setup.exe` installs LocalRack to `C:\Program Files\LocalRack`, adds it to the Start menu (with an optional desktop icon), and registers an uninstaller under **Settings > Apps > Installed apps**. If LocalRack is running during an upgrade, setup asks you to exit it first instead of replacing the app while your services run. Uninstalling removes the **Start with Windows** entry and keeps your projects in `%APPDATA%\LocalRack`.
- **No idle CPU use.** Logs are now processed only when a service prints something. Before, LocalRack woke up 10 times a second whenever any service was running, which caused small, regular CPU spikes.
- **Develop LocalRack while using it.** Debug builds run as a separate app, **LocalRack-Dev**, with their own data, single-instance lock, and startup entry. They no longer hand off to the installed copy or change its settings.

## Install

Download one of these below:

- **Installer (recommended):** `LocalRack-v1.1.0-win-x64-setup.exe`. Run it and approve the administrator prompt.
- **Portable:** `LocalRack-v1.1.0-win-x64.exe`. A single self-contained executable; nothing is installed.

Both are for 64-bit Windows 10 and 11, and neither needs .NET installed.

**Coming from v1.0.0?** Your projects and settings carry over automatically. Exit the old copy before installing. If **Start with Windows** was on, the installed copy updates the startup entry to its new location the first time it runs, after which you can delete the old portable exe.

To verify a download, compare its SHA-256 hash with `SHA256SUMS.txt`:

```powershell
Get-FileHash .\LocalRack-v1.1.0-win-x64-setup.exe -Algorithm SHA256
```

## Known limitations

- The installer and the executable are not code-signed yet, so Windows SmartScreen may show "Windows protected your PC" on first run. Choose **More info**, then **Run anyway**.
