# LocalRack v1.3.0

LocalRack can now tell you when a new release is out and update itself, and services find tools like `pnpm` again.

## Highlights

- **Update notifications.** A few seconds after launch, LocalRack checks GitHub for a newer release. If there is one, it asks whether to update. Say yes and it downloads the installer, verifies its SHA-256 against the release's `SHA256SUMS.txt`, stops your running services, and starts setup, which relaunches LocalRack when it finishes. Nothing is installed without your confirmation. If you're hidden in the tray, the prompt waits until you open the window. In **Settings > Updates** you can turn the startup check off or press **Check now**. The portable exe can't update itself, so it opens the release page instead.
- **Fix: services couldn't find `pnpm` or other user-installed tools.** Services inherited their PATH from whatever launched LocalRack, usually Explorer. If Explorer's copy was stale or missing your user PATH, commands such as `pnpm dev` failed with "not recognized" even though they worked in a normal terminal. LocalRack now rebuilds PATH from the Windows registry (machine plus user) every time it starts a service.

## Install

Download one of these below:

- **Installer (recommended):** `LocalRack-v1.3.0-win-x64-setup.exe`. Run it and approve the administrator prompt.
- **Portable:** `LocalRack-v1.3.0-win-x64.exe`. A single self-contained executable; nothing is installed.

Both are for 64-bit Windows 10 and 11, and neither needs .NET installed.

**Coming from an earlier version?** Your projects and settings carry over automatically. Exit the running copy before installing. Versions before 1.3.0 can't check for updates, so install this one manually.

To verify a download, compare its SHA-256 hash with `SHA256SUMS.txt`:

```powershell
Get-FileHash .\LocalRack-v1.3.0-win-x64-setup.exe -Algorithm SHA256
```

## Known limitations

- The installer and the executable are not code-signed yet, so Windows SmartScreen may show "Windows protected your PC" on first run. Choose **More info**, then **Run anyway**. The update check verifies a checksum published in the same release, which protects against corrupted downloads but is not a substitute for code signing.
