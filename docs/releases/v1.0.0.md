# LocalRack v1.0.0

First release of LocalRack, a lightweight Windows app for running and managing your local development services — frontends, APIs, workers — from one place.

## Highlights

- **Projects and services.** Group services under projects, each with its own working folder and command. Add, edit, rename, and delete from the UI; everything is saved to `%APPDATA%\LocalRack`.
- **Vault and tabs.** The Home page lists every project with its service count and a running badge. Open projects as tabs; open tabs are restored on the next launch.
- **One-click start and stop.** Run commands with PowerShell or Command Prompt, chosen per service. Stopping a service shuts down its whole process tree, including child processes such as Node, Vite, and uvicorn's reload workers, so nothing is left holding a port.
- **Live logs.** Output streams in real time with full terminal colors. Real errors are flagged in red with an `[ERR]` prefix, long lines wrap, and each service keeps its latest 2,000 lines.
- **Terminal-style selection.** Drag to select any text, double-click to select a word, and copy with Ctrl+C or the right-click menu.
- **System tray.** Optionally keep LocalRack running in the tray when you minimize or close the window, so your services keep running in the background.
- **Start with Windows.** Optionally launch LocalRack when you sign in, quietly in the tray if tray mode is on.

## Install

Download `LocalRack-v1.0.0-win-x64.exe` below and run it. No installer and no .NET install needed; it is a single self-contained executable for 64-bit Windows 10 and 11.

To verify the download, compare its SHA-256 hash with `SHA256SUMS.txt`:

```powershell
Get-FileHash .\LocalRack-v1.0.0-win-x64.exe -Algorithm SHA256
```

## Known limitations

- The executable is not code-signed yet, so Windows SmartScreen may show "Windows protected your PC" on first run. Choose **More info**, then **Run anyway**.
- Idle memory use is around 50 MB, which is mostly WPF's own baseline.
