# LocalRack v1.2.0

LocalRack can now start or stop all of a project's services with one click.

## Highlights

- **Start All / Stop All.** Every project card on the home page has **Start All** and **Stop All** buttons, so you can bring a whole project up from the home page without opening it. The same two buttons sit next to **Add Service** inside each project tab. Services run in the background, so the window stays responsive.
- **Buttons that match the project's state.** **Start All** is available whenever at least one service is stopped and starts only the stopped ones, leaving running services alone. It is disabled once everything is running. **Stop All** is available whenever at least one service is running and is disabled when nothing is. Both update as services start, stop, exit, or are added and removed.
- **Wider services sidebar.** The sidebar in a project tab is slightly wider (290 px, down to a 250 px minimum) so the new buttons no longer crowd the "Services" title.

## Install

Download one of these below:

- **Installer (recommended):** `LocalRack-v1.2.0-win-x64-setup.exe`. Run it and approve the administrator prompt.
- **Portable:** `LocalRack-v1.2.0-win-x64.exe`. A single self-contained executable; nothing is installed.

Both are for 64-bit Windows 10 and 11, and neither needs .NET installed.

**Coming from v1.1.0 or v1.0.0?** Your projects and settings carry over automatically. Exit the running copy before installing.

To verify a download, compare its SHA-256 hash with `SHA256SUMS.txt`:

```powershell
Get-FileHash .\LocalRack-v1.2.0-win-x64-setup.exe -Algorithm SHA256
```

## Known limitations

- The installer and the executable are not code-signed yet, so Windows SmartScreen may show "Windows protected your PC" on first run. Choose **More info**, then **Run anyway**.
