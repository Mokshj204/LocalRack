# LocalRack v1.4.0

Pin and reorder your projects, start several projects together as a group in the order you choose, and switch between light and dark themes.

## Highlights

- **Pin and reorder projects.** Each project card has **Pin/Unpin** and ▲ ▼ buttons (also in the right-click menu). Pinned projects always stay at the top, ▲ ▼ move a project within its pinned or unpinned section, and the order is remembered between launches.
- **Groups.** The Home page now has a **Projects | Groups** toggle. A group bundles several projects so you can start them all with one click on **Start Group**:
  - Add projects, put them in the order they should start, and open a project with its arrow to reorder its services, untick any you don't want, and set a wait (0 to 600 seconds) after each one so the next waits until it's up.
  - Services start top to bottom while the card shows progress, such as "Starting backend › api (2 of 5)" with a countdown. **Stop Group** stops them in reverse order and cancels a start that is still counting down.
  - Groups can be edited, pinned, reordered and deleted like projects. Deleting a project removes it from any groups, and a service that no longer exists is skipped and marked in the summary.
- **Light and dark themes.** **Settings > Appearance** offers System (the default, follows Windows live), Light and Dark. The title bar, scrollbars, menus and dropdowns follow the theme too.

## Install

Download one of these below:

- **Installer (recommended):** `LocalRack-v1.4.0-win-x64-setup.exe`. Run it and approve the administrator prompt.
- **Portable:** `LocalRack-v1.4.0-win-x64.exe`. A single self-contained executable; nothing is installed.

Both are for 64-bit Windows 10 and 11, and neither needs .NET installed.

**Coming from an earlier version?** Your projects and settings carry over automatically, and existing projects keep their current order. LocalRack 1.3.0 can offer this update itself from the startup check, or you can install it manually. Exit the running copy before installing.

To verify a download, compare its SHA-256 hash with `SHA256SUMS.txt`:

```powershell
Get-FileHash .\LocalRack-v1.4.0-win-x64-setup.exe -Algorithm SHA256
```

## Known limitations

- Log lines already on screen keep their old colours when you switch theme. New lines use the new palette.
- Services within a group are ordered inside their project; you can't interleave services from different projects.
- The installer and the executable are not code-signed yet, so Windows SmartScreen may show "Windows protected your PC" on first run. Choose **More info**, then **Run anyway**. The update check verifies a checksum published in the same release, which protects against corrupted downloads but is not a substitute for code signing.
